# 自治体標準オープンデータセットの公開状況

全国の自治体が、デジタル庁の[自治体標準オープンデータセット](https://www.digital.go.jp/resources/open_data/municipal-standard-data-set-test) 31 項目を公開しているかどうかを観測した記録です。1 行が団体 × 項目で、公開していない組み合わせも行として持ちます。判定に使った検索語と、語ごとのヒット数も公開しているので、判定の根拠を確認できます。

## 出典と利用条件

- 各自治体のオープンデータカタログの CKAN API を Queria が観測して作成しています。データ本体は取得せず、件数と組織別の内訳だけを読んでいます
- 項目の定義はデジタル庁「自治体標準オープンデータセット（正式版）」です。1〜17 と 23〜31 はデジタル庁が様式を公開し（データ項目定義書 A〜D）、18 は国土交通省の地質・土質調査成果電子納品要領、19 は都市計画基礎調査、20 はデジタル社会推進実践ガイドブック DS-451-8 実装データモデル（行政）調達、21 は標準的なバス情報フォーマットが様式を定めています
- ライセンスは [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja) です。観測対象の各カタログのデータ本体は含みません

## テーブル

| テーブル | 内容 |
| --- | --- |
| `ods.measurement` | 団体 × 項目の公開状況 |
| `ods.item` | 31 項目の定義と、判定に使った検索語 |
| `ods.portal` | 観測したカタログと、観測できたかどうか |
| `ods.search_word_hit` | 検索語ごとのヒット数（判定の根拠） |

`ods.measurement` の列:

- lg_code: 全国地方公共団体コード（6桁、検査数字付き）
- lg_code_5: 検査数字を除いた5桁
- prefecture_code: 都道府県コード（先頭2桁）
- item_no: 項目番号（1〜31）
- item_key: 項目キー
- item_label: 項目名
- definition_book: データ項目定義書（A〜H）
- is_published: 観測時点で公開を確認できたか
- dataset_count: 一致したデータセット数
- portal_id: 観測したカタログ
- measured_on: 観測日

`lg_code` で lg_code・houjin_bangou・zipcode と結合できます。

## 使い方

項目ごとに、公開を確認できた団体の数を出す:

```sql
SELECT item_no, item_label,
       count(*) FILTER (WHERE is_published) AS published,
       count(*) AS observed
FROM opendata_census.ods.measurement
GROUP BY ALL
ORDER BY item_no;
```

公開していない組み合わせも `is_published = false` の行で持つので、「公開していない」を数えるのに LEFT JOIN は要りません。

## 判定の性質と限界

判定はデータセット名（タイトル）の部分一致による近似で、公式の公表値ではありません。次の癖があります。

タイトルに項目名を含まないデータセットは拾えません。たとえば入札結果を「契約情報」というタイトルで公開している団体は、項目20（調達情報）の検索語に当たらません。実際の公開状況より少なく出る方向に偏ります。

逆に、別の用途のデータセットが当たることがあります。項目25（公営駐車場一覧）の検索語「駐車場」は、観光施設の付帯駐車場を含むデータセットにも一致します。

説明文は見ずタイトルだけを見ます。これは意図的で、フリーテキスト検索にすると件数の桁が変わるためです。BODIK 横断カタログで「オープンデータ一覧」を全文検索すると10,553件（カタログ全体の半分以上）が当たりますが、タイトル限定なら125件になります。

検索語は `ods.item` の `search_words` にあり、語ごとのヒット数は `ods.search_word_hit` で確認できます。ある項目の団体数が少ないとき、公開が少ないのか語が合っていないだけなのかを切り分けられます。

## 観測範囲

`ods.portal` に載っているカタログだけが観測対象で、そこに参加していない団体は `measurement` に行がありません。行が無いことは「公開していない」ではなく「観測していない」を意味します。全国の団体を分母にした割合を出すときは、lg_code と結合してください。

個別自治体のサブサイト（`odcs.bodik.jp/<団体コード>/` など）は多くが CMS のフロントで API を持たないため、横断カタログ側から一括で観測しています。
